# Pofinyo 1.2.1 marka güncellemesi

README baştan düzenlendi: Pofinyo kimliği, güncel FSRS-6 modeli, İngilizce temel rotası, özgün ekranlar, kurulum, gizlilik ve kapsam sınırları. Eski sabit tekrar günleri ve çelişkili tarihsel özellik listeleri çıkarıldı.

Özgün SVG ikon, krem rengi karakterin yüzünü, yaprak tacını ve yeşil arka planını kullanır. PNG 512 px; Windows ICO 16/24/32/48/64/128/256 px; ICNS 256 ve 512 px. Uygulama penceresi, sistem tepsisi, paket ve kısayollar aynı ikon kaynağını kullanır. Görünür uygulama adı ve paketler Pofinyo olarak güncellendi.

Mevcut kayıtların korunması için dahili uygulama kimliği, profil adı, yerel origin ve yedek alanları değiştirilmedi. 32 model/veri/pencere testi ile üç gerçek Electron senaryo grubu geçti. Yerel README bağlantıları kontrol edildi. İkon görsel olarak incelendi. Başlık düğmelerinde açık no-drag ve küçülmeme kuralları kullanıldı; yerel masaüstü testinde üstte tutma başlangıçta, boyut geçişleri ayrı doğrulandı.
